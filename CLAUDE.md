# Заміни — застосунок для пошуку замін учителів

Повна специфікація й домовленості: [zaminy-tz.md](zaminy-tz.md). Читати перед будь-якою
зміною моделі даних чи логіки ранжування — там зафіксовано, чому все влаштовано саме так.

## Стек

Vite + React + TypeScript, звичайний CSS (mobile-first, без UI-фреймворків), Vitest.
Стан — localStorage, без бекенда. GitHub-синхронізація й авторизація — не в цій сесії.

## Команди

- `npm run dev` — дев-сервер (`server.host: true` у vite.config.ts, слухає всі інтерфейси —
  так виправили баг, коли осиротілий процес слухав лише IPv6 і сторінка була порожня)
- `npm test` — юніт-тести ранжування
- `npx tsc -b` — перевірка типів

## Стан проєкту після сесії 5 (2026-08-08)

**Багфікси** (знайдено й виправлено дорогою, не частина запланованої фічі):
- `toISOString().slice(0, 10)` конвертує в UTC, а не бере локальну дату — у
  поясі UTC+3 це відкушувало день назад біля півночі. Ламало стрілки дати в
  `CalendarScreen.tsx` і `currentMonth()` у `profile/stats.ts`. Виправлено
  спільними `todayIso()`/`addDays()` у `src/ranking/presence.ts` (рахують
  локальну дату напряму через `getFullYear`/`getMonth`/`getDate`) — інші
  місця, що рахують дату, мають брати звідти, а не заново писати
  `toISOString`.
- У `profile/stats.ts` (`classLoad`, з сесії 1-2) у рядку-ключі Map замість
  пробілу був буквальний нульовий байт — не ламало функціонально (ключ і так
  лишався унікальним), але робило файл "бінарним" для git-діффа. Замінено на
  пробіл.

**Парсер тексту запиту на заміну** (розділ 6 ТЗ) — останній нетривіальний
шматок кроку 3 "Решта":

  коротші 3 символів ігноруються), дата (сьогодні/завтра/день тижня/"число
  місяця", пріоритет у цьому порядку), "на весь день", час ЧЧ:ММ, номер уроку.

## Рішення, уточнені під час сесії 1 (в ТЗ дослівно не було)

- Тир визначається трьома ознаками — куратор / викладає клас / присутній
  (`src/ranking/rank.ts`, `classifyTier`). Погодинність (`Teacher.isHourly`) — лише
  позначка в профілі для довідки, на тир не впливає. Якщо погодинник фактично доступний
  до/після власного уроку — це вручну вказаний звичайний блок `presence`, без спецлогіки.
- Бонуси (золота година, 3+ відмов поспіль) підіймають кандидата всередині БУДЬ-ЯКОГО
  тиру, не тільки тиру 1.
- Кандидат, який сам має урок у цьому слоті, виключається зі списку повністю —
  незалежно від того, під який тир він би інакше підійшов.
- Позначка про авдиторію — властивість слоту (однакова для всіх кандидатів у списку),
  а не властивість конкретного кандидата.
- "Уроків сьогодні" на картці — тільки базовий розклад цього дня тижня, без нашарування
  тижневих замін (спрощення, тижневий шар ще не реалізований).
- Мовчання (`silent`) під час підрахунку "відмов поспіль" просто пропускається, а не
  переривається — воно не має рахуватись як відмова.

## Рішення, уточнені під час сесії 2 (в ТЗ дослівно не було)

- `closedVia` при згоді визначається статусом заміни в момент кліку, а не окремим
  вибором каналу: `"chat"` для звичайного опитування, `"voluntary"` якщо заміна вже була
  в статусі `in-chat` (`src/data/actions.ts`, `recordAttempt`).
- Статус "Тупик" пишеться без причини (`взяла сама` / `урок скасовано` / `класи
  об'єднано` з розділу 3 ТЗ ніде не зберігається) — свідоме спрощення, за 3 роки цей
  статус траплявся вкрай рідко.
- Розсилка завчасних замін у чат — **одне спільне повідомлення** на всі поточні
  завчасні заміни зі статусом `open` (розділ 1/5: "списком"), а не окреме на кожну.
  Кнопка "відкрити чат" ховається, доки `GROUP_CHAT_INVITE_URL` в `settings.ts`
  порожній — реального посилання групи ще немає.
- Статистика на профілі (заміни/відмови/мовчання) — за **поточний календарний місяць**
  від реальної дати пристрою, так само як лічильник "замін за місяць" у ранжуванні.
  Наслідок для тестування: сідові дані датовані вереснем 2026, а реальна дата в момент
  розробки — серпень 2026, тож на живому екрані профілю це очікувано покаже нулі.
- Текст WhatsApp-повідомлення (розділ 7) — фіналізований дослівно Kate:
  `"Привіт! Потрібна заміна: {день тижня}, {дата}, урок {N} ({початок}–{кінець}), {клас}
  клас. Підкажи, будь ласка, чи зможеш ти її взяти?"` — без згадки предмета.

## Рішення, уточнені під час сесії 5 (в ТЗ дослівно не було)

- **Сценарій "на весь день" зробили одразу**, а не відклали — Kate обрала

  (дата = сьогодні → термінова, інша дата → завчасна), а не завжди

- **Мінімальна довжина токена для збігу імені — 3 символи.** Без цього

  спрощення, щоб уникнути хибних збігів.
- **Чергування "втрачених" голосних у прізвищах (Кравець → Кравця) і

  рівень спрощення, що ТЗ явно приймає для звичайних відмінкових закінчень

  у коді пробіл, не помилка.
- **Дні тижня для розбору дати — невелика ручна таблиця форм** (називний +

  узагальнення того не вартує.
- **Конфлікт слоту (уже є заміна) блокує створення повністю**, а не просто
  попереджає — Kate ще не просила можливість свідомо перекрити наявну
  заміну, це можна додати пізніше, якщо знадобиться.
